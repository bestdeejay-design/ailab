# Открытый учебник по ИИ

Этот репозиторий содержит открытый учебник по искусственному интеллекту, собранный на базе материалов из открытых источников. Все авторы статей и семинаров указаны в соответствующих разделах учебника.

## Структура репозитория

```

├── .nojekyll                       # Для GitHub Pages (без Jekyll)
├── README.md                       # Этот файл
├── textbook/
│   └── index.html                  # Основной учебник (три колонки, тёмная/светлая тема)
└── knowledge-base/archive/        # Архив первоисточников (для пытливых умов)
    ├── pages/                      # Полные тексты статей (markdown)
    │   ├── article_0018.md         # Статья id=18 (Бахшиев, Романов — нейроны)
    │   ├── article_0019.md         # Статья id=19 (Бахшиев — Pattern Processing)
    │   ├── article_0021.md         # Статья id=21 (Neuro Modeler)
    │   ├── article_0028.md ...     # и другие статьи (всего 91 файл)

    │   ├── predystoriya-impulsnogo-nejrona.md               # Предыстория импульсного нейрона
```

## Как использовать

**Учебник:** откройте `textbook/index.html` — это готовый веб-учебник с трехколоночной версткой (содержание слева, контент в центре, оглавление и цитаты справа), поддержкой тёмной и светлой тем, сносками и авторскими указаниями.

**Архив первоисточников:** папка `knowledge-base/archive/pages/` содержит полные тексты статей в формате markdown. Они оставлены для тех, кто хочет изучить оригиналы глубже. Прямых ссылок на внешние сайты в учебнике нет — только имена авторов.

## Публикация на GitHub Pages

1. Запушьте репозиторий на GitHub
2. В настройках репозитория (Settings → Pages) включите GitHub Pages
3. Выберите ветку `main` (или `arena/354ef5c8-ailab`) как источник
4. Учебник будет доступен по адресу вашего GitHub Pages

## Лицензия и использование

Учебник распространяется открыто. Авторы первоисточников указаны в разделах. Полные тексты статей хранятся в архиве первоисточников этого репозитория.
