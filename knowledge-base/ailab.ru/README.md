# Библиотека знаний ailab.ru

Локальная копия библиотеки знаний сайта [ailab.ru](https://ailab.ru) — лаборатории искусственного интеллекта (моделирование биоподобных систем, нейросети, распознавание образов, управление, аниматы, бионика).

## Источник и способ сбора

- Источник: https://ailab.ru (Joomla + DokuWiki)
- Дата сбора: 2026-11-09
- СборPerformed: страницы сайта сохщены в формате Markdown (через посредник fetch_page, прямое HTTP-подключение к ailab.ru из sandbox ограничено)
- robots.txt сайта: https://ailab.ru/robots.txt (разрешено: /, /wiki/, /media/dmdocuments/)

## Структура коллекции

| Папка | Содержание |
|-------|------------|
| `pages/` | Статьи и разделы сайта (Joomla-контент) |
| `wiki/` | Страницы DokuWiki (`wiki.doku.php`) |
| `resources/files.md` | Каталог файлов из `/media/dmdocuments/` (ссылки на скачивание) |
| `resources/docman.md` | Ссылки на загрузки через DocMan (`com_docman`) |
| `sitemap.xml` | Сырой выгрузка sitemap сайта |

## Состав сайта ailab.ru

- **Исследования**: Аниматы, Бионика, Распознавание, Управление, Образование, Философия ИИ
- **Разработки**: RDK, Neuro Modeler и др.
- **Ресурсы**: файловая библиотека (msdk, nmsdk, презентации семинаров, статьи), архивы AI Community (2003, 2006, 2008, 2009)
- **Вики**: пространства имён исследования, разработки, словари, playground, talk, wiki
- **Форум**: Kunena (отдельно, не собран в полном объёме)
- **Новости**: http://ai-news.ru/ (внешний ресурс)

## Важное

Бинарные файлы (PDF, DOC, PPT, ZIP, RAR, EXE, MP3, WMA) из `/media/dmdocuments/` не скачивались — только проиндексированы со ссылками на исходные URL. Для получения файлов скачивайте их напрямую с https://ailab.ru/media/dmdocuments/.
