# Эволюция: Из воды на сушу

Авторы: Ерусалимчик Дан, Ори Коэнов.

Курсовая работа по курсу Искусственная Жизнь. Университет Бар-Илан, факультет Компьютерных Наук.

##### Аннотация:

По теории Эволюции жизнь зародилась в воде. Морские животные отрастив себе конечности способные к перемещению по твердой поверхности постепенно переместились из воды на сушу.

Цель этой работы смоделировать подобный сценарий развития событий и сравнить его с альтернативным. Дополнительно будут сделаны выводы, как используя факты из теории Эволюции можно ускорить процесс схождения генетических алгоритмов.

В данной работе, для моделирования эволюционного процесса будет использоваться система симуляции Framesticks. Эта система позволяет при помощи эволюционного процесса создавать объекты подобные живым существам.
